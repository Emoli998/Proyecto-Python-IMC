# Calculadora de IMC en Python
Este proyecto consiste en calcular el Índice de Masa Corporal (IMC) mediante datos solicitados al usuario, como su nombre, edad, peso y estatura.
Utilizando estos datos, el programa calcula el IMC y muestra un resumen de la información introducida junto con el resultado del cálculo, redondeado a dos decimales.

La fórmula utilizada es:
IMC = peso / (estatura²)
El peso debe expresarse en kilogramos y la estatura en metros.

¿Cómo ejecutar el programa?
Para ejecutar este programa, se necesita tener Python instalado en la computadora. También se puede utilizar Visual Studio Code como editor de código.

Pasos para ejecutar el programa:
1. Abrir Visual Studio Code.
2. Abrir la carpeta donde se encuentra el archivo "calculadora_imc.py".
3. Abrir una terminal dentro de Visual Studio Code.
5. Introducir los datos solicitados por el programa.
6. Consultar el resumen de los datos introducidos y el resultado del IMC.
El programa incluye validaciones para evitar campos vacíos y comprobar que la edad, el peso y la estatura sean datos numéricos válidos.
